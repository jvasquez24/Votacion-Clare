📖 Cómo configurar Firebase

  • Ve a console.firebase.google.com y creá un proyecto nuevo (gratis)
  • Clic en el ícono </> Web → registrá la app → copiá los datos de firebaseConfig
  • En el menú, activá Realtime Database → Crear base de datos → elegí Modo de prueba
  • Pegá los datos en los campos de arriba y hacé clic en Conectar Firebase
  • El punto se pone verde ✓ — desde ese momento todo es tiempo real ⚡
